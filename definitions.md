# Definitions

1. Use case

A Use Case defines a sequence of interactions between an actor and the system to achieve a specific business goal.

- Actor: the person or system initiating the interaction ( HR, BOD, Analytic Cron Job )
- Behavior: the dialogue/flow between user and the system( Uploading a Spreadsheet )
- Business Goal: the valuable output that solves a real business problem( import initial employee data, access employee 360 degree Profile )
