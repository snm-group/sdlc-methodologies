## Case study 1 : Employee Management

### Business Problems

- Company manage employees using Google SpreadSheet, it is a convenience way, HR or BOD can see list of employees in one place.
- But from time to time, this list increase, not only number of employees but also additional data from mandatory information, work histories, salary histories, days off, education, certifications, skills, ...
- The file becomes harder to manage. It is also very hard to have an overview of an employee even though we have collected a lot of data.

### Solution

We decided to make a web application to replace the main Google SpreadSheet. The goal is after finishing the application, we'll import data from current Google Spreadsheet so that HR and BOD can start using it.
